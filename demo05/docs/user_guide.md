# 使用说明

## Web 功能

- 数据看板：展示房源总数、覆盖区域、平均租金、平均单价和各维度图表。
- 导入演示数据：无需真实爬虫环境即可体验分析功能。
- 启动采集：选择平台、城市和页数后执行 Selenium 采集。
- 房源查询：按区域、户型、最低租金和最高租金筛选房源。
- 用户功能：支持注册、登录、退出。

## 爬虫准备

1. 安装 Chrome 浏览器。
2. 安装与 Chrome 版本匹配的 ChromeDriver，或使用 Selenium Manager 自动管理驱动。
3. 确认网络可以访问目标站点。
4. 控制采集页数和访问间隔，避免对目标站点造成压力。

## 常见问题

### 页面没有数据

先在首页点击“导入演示数据”，或执行：

```powershell
flask --app run seed
```

### 图表中文显示为方框

Windows 通常自带微软雅黑字体。如果服务器缺少中文字体，请安装中文字体或在 `app/services/analytics.py` 中调整 Matplotlib 字体配置。

### 真实爬虫采集不到数据

租房平台页面结构和反爬策略会变化。可根据当前页面 DOM 修改对应平台文件中的 CSS 选择器和文本解析规则。
