# 智能火车票查询系统

这是一个基于 Python Flask 的真实火车票查询项目。系统从 12306 获取车站、余票和票价数据，并在 12306 直达查询不理想时，自动组合一次中转路线，例如“广州 -> 北京 -> 铁岭”。

## 功能

- 查询真实 12306 直达车次
- 自动选择方向合理的中转城市
- 组合真实车次形成一次中转路线
- 查询每段最低票价和席别余票
- 按距离、价格、时间、中转次数综合排序
- 支持偏好：综合、距离最短、价格最低、时间最短、少换乘

## 运行

```bash
pip install -r requirements.txt
python main.py
```

浏览器打开：

```text
http://127.0.0.1:5000
```

## 说明

系统只做查询、推荐和路线规划，不实现抢票、自动下单、绕过验证码或高频刷票。12306 可能会因为访问频率、日期范围、维护状态或网络环境返回空结果，系统已加入短缓存和请求间隔控制。
